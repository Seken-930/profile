flex と fixed:
メニューバーを fixed（固定）にすることで、右側のコンテンツが長くてもメニューは常に左側に表示され続けます。その分、メインコンテンツには ml-64（サイドバーの幅分だけ左に余白を空ける）を設定して重ならないようにしています。

useLocation:
現在どのページにいるかを自動で判定しています。今見ているページのボタンだけ背景色が変わる（variant="secondary"）ようになっているので、ユーザーが迷子になりません。

Lucide React:
lucide-react というライブラリのアイコンを使っています（Viteの初期設定で入っていることが多いですが、もしエラーが出たら npm install lucide-react を実行してください）。
